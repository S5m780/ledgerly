# Ledgerly

**AI-powered personal finance program creator — your whole money life, finally in one place.**

Ledgerly is a personal finance app that unifies personal and business spending, smart budgets, and an AI that builds you a custom money tracker for *any* goal — paying down debt, saving, investing, and more. Instead of forcing every user into the same rigid template, Ledgerly adapts to how you actually manage money.

## 🔗 Live site

**[https://s5m780.github.io/ledgerly](https://s5m780.github.io/ledgerly)**

The early-access landing page is deployed via GitHub Pages.

## ✨ Features

- **AI-built money programs** — Describe any goal in plain English ("help me pay off $4k in credit-card debt," "save $300/month for a trip") and Ledgerly's AI instantly builds a tailored, interactive tracker with the right fields, calculations, and insights.
- **Personal & business, side by side** — Track every expense and income stream in one ledger. Flag entries as personal or business and tag deductibles so freelance and side-hustle math stays clean all year.
- **Budgets that hold** — Set monthly limits per category and a savings goal, watch progress in real time, and get nudged *before* you blow past a line.
- **AI insights, not just charts** — A clear read on where you stand, what's off track, and the single next action that moves you forward — in plain language.
- **Connect your bank** — Securely sync transactions so your ledger stays current, or add entries by hand. Your call.

## 🛠 Tech

This landing page is a single, self-contained `index.html` file (HTML, CSS, and vanilla JavaScript — no build step, no dependencies). It's deployed straight from the `main` branch via GitHub Pages.
